# 📚 Tài Liệu Kỹ Thuật RehabAI (Technical Documentation)

Thư mục này chứa các tài liệu tổng hợp kiến trúc hệ thống và cơ chế mô hình nhận diện trong dự án **RehabAI**.

## 📑 Danh Sách Tài Liệu

1. **`BAO_CAO_TONG_HOP_DU_AN_REHABAI.md`**:
   - Báo cáo tổng thể về bài toán, mục tiêu nghiên cứu, phương pháp luận AI thị giác máy tính và lộ trình hoàn thiện sản phẩm.
   - Phân tích chi tiết bộ dữ liệu lâm sàng (491 video), cơ chế chuẩn hóa động học (Kinematic Normalization), quy trình huấn luyện chéo Leave-One-Subject-Out (LOSO).

2. **`TAI_LIEU_MO_HINH_NHAN_DIEN_VA_CANH_BAO_REHABAI.md`**:
   - Tài liệu kỹ thuật chuyên sâu về mô hình nhận diện bài tập (Gập/duỗi khuỷu tay và Mở bàn tay).
   - Cơ chế phát hiện cờ đỏ y tế (Medical Red Flags), đánh giá mức độ đau VAS, và hệ thống phân tích an toàn 2 lớp (Two-Layer Clinical Safety System).

3. **`assets/rehabai_home.png`**:
   - Ảnh chụp giao diện bảng điều khiển trung tâm (Web Care Dashboard) của hệ thống RehabAI.
